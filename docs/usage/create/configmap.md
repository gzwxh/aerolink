# ConfigMap：创建与修改

ConfigMap 存非机密的配置：配置文件内容、命令行参数、环境变量值。Pod 里可以按卷挂载（变成文件）或作为环境变量使用。

## 创建入口

左侧「配置 → ConfigMaps」→ 右上角「创建」；或用详情页「更多」→「克隆」。

## 表单

![ConfigMap 创建页](/images/usage/create-configmap.png)

顶部是命名空间、名称（必填）、描述（写进注解）。下面四个页签：

| 页签 | 内容 |
| --- | --- |
| 数据 | 键值对，值是文本，支持多行（贴配置文件内容就放这里） |
| 二进制数据 | 键值对，值按 base64 存，可以从本地文件加载 |
| 标签 & 注释 | `metadata.labels` / `annotations` |
| 编辑 YAML 并创建 | 最终清单，可以直接改 |

### 数据

一行一个键：`application.yaml` → 文件内容，`LOG_LEVEL` → `info`。键名必须是合法的 ConfigMap key（字母数字、`-`、`_`、`.`），页面会校验。

多行值直接在输入框里换行；从文件加载只在「二进制数据」页签有按钮。

### 二进制数据

值以 base64 编码存进 `data`。证书、keystore、图片这类非文本内容走这一页，选文件后页面会读成 base64。

## 在 Pod 里怎么用

- **挂成文件**：容器页签的「存储」里加一个 ConfigMap 卷，再在容器「存储」里挂到某个路径。改 ConfigMap 后，挂载的文件最终会更新（有分钟级延迟）。
- **当环境变量**：表单的「环境变量」只支持直接写值，`valueFrom.configMapKeyRef` 这种引用要写在 YAML 里。
- 改完环境变量形式的引用需要重建 Pod（或滚动重启负载）才生效。

## 修改

| 改什么 | 怎么改 |
| --- | --- |
| 键值、二进制数据、标签注解 | 行操作「编辑」进表单页 |
| `immutable: true`、表单没建模的字段 | 详情页「YAML」页签 |

ConfigMap 没有容器、终端和回滚，行操作里只有编辑、查看 YAML、管理标签/注解、删除。

::: warning 不要存密钥
ConfigMap 是明文存储、谁有读权限谁就能看到。口令、token、证书私钥放 [Secret](./secret.md)。
:::
