# 第 1 步：登录与账号

## 打开地址

管理员给你的地址打开后是登录页，标题「访问 Kubernetes 控制台」。能用的登录方式由管理员在「系统设置 → 安全管理」里开启，你看到的可能只有其中一两种。

![登录页：① 用户名 ② 密码 ③ 当前方式登录按钮 ④ 切换本地账号登录](/images/usage/login-guided.png)

| 编号 | 位置 | 怎么用 |
| --- | --- | --- |
| ① | 用户名 | 填管理员发给你的账号 |
| ② | 密码 | 填密码；右侧小眼睛可切换明文，方便核对有没有多打空格 |
| ③ | 登录按钮 | 文字跟着当前方式变：LDAP 页签下是「LDAP 登录」，本地账号下是「密码登录」。点它就提交 |
| ④ | 底部链接 | 默认是 LDAP 登录；用本地账号时点「使用本地账号登录」切过去 |

登录页常见两种形态：默认 LDAP（上图，底部是「使用本地账号登录」链接）；也能配置成本地登录（下图，按钮是「密码登录」，底部链接变成「使用 LDAP 账号登录」）：

![登录页：本地密码登录；底部链接可切换到 LDAP 账号登录](/images/usage/login-local.png)

| 你看到的 | 怎么做 |
| --- | --- |
| 用户名 / 密码 | 填进去点「密码登录」 |
| 「LDAP」页签 | 切到 LDAP 页签用域账号登录，按钮是「LDAP 登录」；只启用 LDAP 时，底部链接「使用本地账号登录」可切回密码登录 |
| 「使用 xxx 登录」按钮 | OAuth / OIDC 单点登录，点一下跳到公司身份服务，认证完自动跳回来 |
| 「验证码」输入框 | 填 4 位验证码（管理员开启图形验证码后才会出现） |
| 「MFA」弹窗 | 账号要求 MFA 但还没绑定，跟着弹窗先绑定（扫码或用验证码）再登录 |

## 登录失败的提示对照

登录失败时界面的提示通常就是结论，按下面处理即可：

| 提示 | 含义与处理 |
| --- | --- |
| 用户名或密码错误 | 密码不对。系统**没有自助找回密码**，找管理员重置 |
| 当前 IP 不允许登录 / 来源地址不允许登录 | 当前网络不在允许的登录来源里，换到受控网络（VPN/办公网）再试 |
| 登录尝试次数过多，请稍后再试 | 触发了登录尝试限制，等锁定窗口过去 |
| 账号已禁用 / 账号已过期 | 联系管理员 |
| 认证成功，但账号不属于 xxx 的允许群组 | 让管理员把你加进允许的群组 |
| 权限不足，无法访问此应用 | 账号还没分配角色，让管理员在「权限管理」里分配 |

::: tip 密码忘了怎么办
本系统不提供自助重置入口。让管理员在[用户管理](../config/user-management.md)里点「重置密码」，或让你用 LDAP / OAuth 登录。
:::

## 绑定 MFA

账号被要求 MFA 时：

1. 用认证器 App（如手机上的 TOTP 应用）扫描弹窗里的二维码；
2. 输入 App 当前显示的 6 位验证码完成绑定；
3. 之后每次登录都要多输这一步。

改密码、重新绑定 MFA 都在「用户信息 → 安全」里。

## 登录之后：账号设置

头像菜单 →「用户信息」，三个页签：

| 页签 | 能改什么 |
| --- | --- |
| 资料 | 显示名称、头像 |
| 安全 | 修改密码、MFA 绑定 |
| 外观 | 主题、字体、显示缩放 |

外观设置只影响你自己，切换后立即生效，不需要刷新。
