# 使用指南

这一组页面写给**拿到地址和账号的普通使用者**：不涉及部署、不涉及二次开发，只讲"我怎么把日常这几十次操作做完"。

## 第一次进来，先照这张图认路

![控制台总览：① 集群切换器 ② 左侧导航 ③ 全局搜索 ④ 创建资源 ⑤ 头像菜单](/images/usage/overview-guided.png)

| 编号 | 位置 | 干什么 |
| --- | --- | --- |
| ① | 左上角 | **集群切换器**：显示你正在操作的集群，多集群时先在这里核对 |
| ② | 左侧栏 | **资源导航**：按「集群 / 工作负载 / 流量 / 存储 / 配置」分组，点资源类型进列表 |
| ③ | 顶栏中间 | **全局搜索**：按 `Ctrl + K`（macOS `Cmd + K`），输名字找资源、跳页面 |
| ④ | 顶栏右侧 | **创建资源**：有创建权限才显示；没有这个「+」就是没授权 |
| ⑤ | 右上角 | **头像菜单**：用户信息（改密码 / MFA）、自定义侧边栏、退出登录 |

::: tip 入口按权限显示
图里这些入口不是人人都有：看不到「+」、系统设置这类按钮，说明账号没有对应权限，不是界面坏了。处理方式见[第 6 步：权限不够怎么办](./permissions.md)。
:::

## 跟着做：最常用的几个动作

新用户当天就会用到的动作，每个都配了带编号的截图，照着点即可：

1. **把一个应用部署上线** → [跟着做：部署一个应用到集群](./deploy-app.md)
2. **找到并查看一个资源** → [第 3 步：找到并查看资源](./resources.md)
3. **看日志、进容器终端** → [第 4 步：日志与容器终端](./logs-terminal.md)
4. **下载文件、日志或导出列表** → [下载与上传](./downloads.md)
5. **创建一个 Deployment、改镜像、扩缩容** → [第 5 步：创建与常用操作](./common-operations.md)

界面上的词不认识（Pod、Deployment、命名空间、副本……）先翻[名词解释](./glossary.md)，每项一句话。

## 按顺序读

六页大约 15 分钟，也可以直接跳到你卡住的那一步：

| 步骤 | 你会学到 | 页面 |
| --- | --- | --- |
| 1 | 用哪种方式登录，登录不上时提示是什么意思 | [登录与账号](./login.md) |
| 2 | 顶栏、左侧栏、集群切换器分别管什么 | [认识界面](./interface.md) |
| 3 | 怎么快速找到资源、在详情页看什么 | [找到并查看资源](./resources.md) |
| 4 | 看日志、进容器终端、排查起不来的 Pod | [日志与容器终端](./logs-terminal.md) |
| 5 | 创建 Deployment / Pod / CronJob、改配置、改镜像、扩缩容、重启、删除、回滚 | [创建与常用操作](./common-operations.md) |
| 6 | 按钮不见了、报"没有权限"怎么办 | [权限不够怎么办](./permissions.md) |

::: tip 先记住两件事
1. **一切操作都作用于左侧栏选中的那个集群**，多集群环境下先确认在哪个集群再动手。
2. **界面按权限渲染**：看不到入口就是没权限，不是 Bug，找管理员加授权即可。
:::

::: tip 要建 Deployment / Pod / CronJob？
入口与表单结构看[第 5 步：创建与常用操作](./common-operations.md#创建资源)；**某一类资源要填什么、带截图的分步说明**在[按资源类型创建与修改](./create/)里，Deployment、StatefulSet、DaemonSet、Job、CronJob、Pod、Service、ConfigMap、Secret 各一页。

要一次下发多份 YAML（比如同时建 Deployment 与 StatefulSet），用顶栏「+」→「创建资源」并选「空模板」：多份文档用 `---` 分隔，命名空间分别写在各自的 `metadata.namespace` 里。
:::

## 按角色找路径

- **只看状态、偶尔排障**：登录 → [认识界面](./interface.md) → [日志与容器终端](./logs-terminal.md)
- **要建工作负载、改配置、发版**：[创建与常用操作](./common-operations.md) → [资源历史](../features/resource-history.md)
- **要装应用/中间件**：[Helm 管理](../features/helm-management.md)
- **负责集群接入、账号与权限**：这类内容在给管理员的[管理配置](../config/index.md)里
- **负责把系统装起来**：[快速部署](../guide/quick-deploy.md) → [安装指南](../guide/installation.md)
