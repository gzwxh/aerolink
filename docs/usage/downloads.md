# 下载与上传：文件、日志、列表、YAML

界面里能"下载"的地方有四处，用途和权限各不相同。这一页按场景讲清楚。

## 下载容器里的文件

进 Pod 详情页 →「文件」页签：

![Pod 文件页签：① 容器选择 ② 当前路径 ③ 上传 ④ 行内预览 / 下载](/images/usage/pod-files-demo-guided.png)

| 编号 | 位置 | 说明 |
| --- | --- | --- |
| ① | 左上角 | 一个 Pod 多个容器时先选对容器，文件是容器内的 |
| ② | 路径栏 | 当前目录；回车可跳转，左侧按钮回上级 / 根目录，旁边是刷新 |
| ③ | 右上角 | 上传文件到当前目录（需要上传权限） |
| ④ | 每行末尾 | 眼睛是预览，下载图标是下载；**目录行也能下**，会打包成 `.tar` |

::: tip 下载整个目录
下载单个文件直接点行末的下载图标；要拿一整个目录，进目录后点下载图标，拿到的是 `.tar` 包。
:::

## 上传文件

同一个「文件」页签，右上角「上传」→ 选择本地文件。注意：

- 上传是**覆盖式**的：目录里已有同名文件时，页面会明确提示"继续上传会直接覆盖原内容且无法恢复"，确认后才上传。
- 上传大小受容器内可用空间限制；大文件建议走对象存储或 `kubectl cp`。
- 上传需要「容器文件上传」权限，按钮置灰就是没授权。

## 下载日志

Pod 日志工作区（页头「日志」按钮打开）的工具栏右侧有下载图标：

![日志工作区：工具栏右侧的下载按钮](/images/usage/pod-logs-demo-guided.png)

点了会下载当前视图的日志为 `.txt` 文件。注意：

- 下载的是**当前已加载 / 已过滤**的内容，取决于日志面板的过滤与行数设置；
- 要多副本的日志请进具体 Pod，不要用工作负载级聚合视图；
- 容器重启前的日志先切到"上一个容器日志"再下载。

## 导出列表数据（CSV / JSON）

Deployments、StatefulSets、DaemonSets、Nodes 等列表工具栏右侧有「下载」按钮：

![列表下载菜单：① 下载按钮 ② 当前所选 ③ 全部](/images/usage/list-download-demo-guided.png)

| 编号 | 范围 | 导出哪些行 |
| --- | --- | --- |
| ② | 当前所选 | 只导出勾选的行；没勾选时置灰 |
| ③ | 全部 | 当前搜索 / 列筛选后的全部行，翻页不影响范围 |

格式选 CSV（Excel/WPS 直接打开，带 UTF-8 BOM，中文不乱码）或 JSON（给脚本处理）。导出列等于**当前可见列**，隐藏列不会出现。细节见[下载列表数据](./resources.md#download-list)。

## 下载 YAML

| 对象 | 在哪下 |
| --- | --- |
| 节点、命名空间 | 行操作菜单 →「下载 YAML」 |
| 其他资源 | 详情页「YAML」页签里复制内容，自己保存为文件 |
| 行操作「查看 YAML」 | 只读弹窗，用于核对，没有下载按钮 |

「下载 YAML」拿到的是完整清单，可以 `kubectl apply -f`；「下载」按钮导出的是表格数据，两者不是一回事。

## 下载不了怎么办 {#download-troubleshoot}

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 「文件」页签报"容器不支持文件操作" | 镜像里没有 `ls`/`cat` 等命令（如精简镜像） | 换带 shell 工具的基础镜像，或用 Web 终端 |
| 下载图标置灰 / 上传按钮不可点 | 没有容器文件下载 / 上传权限 | 找管理员授权 `pods/download-file`、`pods/upload-file` |
| 列表「下载」里「当前所选」置灰 | 没有勾选行 | 先勾选要导出的行 |
| 日志下载按钮没反应 | 日志还没加载完或工作区已断开 | 等日志出现 / 重开日志工作区 |

## 这些操作会被审计

查看、下载、上传容器文件都会记入审计（文件操作），能查到操作人、容器与文件路径。导出 CSV 的响应头带内容指纹，可核对文件是否被改动，见[审计与合规](../features/audit-and-compliance.md)。
