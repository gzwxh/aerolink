# 安全策略

账号体系、认证源、密码规则、会话与登录限制都在「系统设置 → **安全管理**」里，分五个页签：认证安全、登录限制、密码安全、会话安全、认证配置。策略保存在数据库的 `security_settings.data` 一个 JSON 字段里，改完立即生效（部分策略带 30 秒缓存，最多滞后半分钟）。

本页讲策略本身；账号的增删改与角色分配见[用户管理指南](./user-management.md)，章节权限与权限绑定见 [RBAC 配置指南](./rbac-config.md)。

## 认证安全

### 登录验证码

「启用登录验证码」默认**关闭**。开启后所有客户端登录都要输图形验证码，会打断脚本化登录（`curl`、CI 里的 API 登录），内网自动化场景要留意。

### 不活跃用户自动禁用

「长期未登录自动禁用」默认 **999 天**（等于不生效）。设置为正数后，超过该天数没有登录记录的账号会被**停用**；每天检查一次，也可以在该页的「用户状态」卡片里立即检查、或把被自动停用的账号批量恢复。

### 异地登录通知

默认**开启**。按登录 IP 是否属于该账号的常用登录城市判断，命中时给本人和订阅了该事件的人发通知，见[通知与公告](../features/notification-and-announcements.md)。

### 多因子认证（动态码）

| 项 | 取值 | 默认 |
| --- | --- | --- |
| 强制绑定动态码 | 不强制 / 强制所有用户 / 仅强制管理员 | 不强制 |
| 第三方认证用户强制绑定 | LDAP 等外部目录账号也要绑定 | 开启 |
| 敏感操作要求动态码校验 | 删除类操作、打开交互终端前再验一次 | 开启 |
| 动态码校验有效期 | 通过一次校验后多长时间内免重复校验（秒） | 60 |
| OTP 应用名称 | 手机验证器里显示的名字 | 鸢联 AeroLink |
| 动态码有效次数 | 允许前几个 30 秒窗口的码（补偿客户端时钟偏差） | 2 |

实现口径：

- 算法是标准 TOTP：SHA-1、30 秒一步、6 位数字；绑定用二维码（`otpauth://` 链接）。
- 强制绑定策略命中时按**请求级**拦截：该账号只能访问绑定动态码相关的接口，其余请求一律拒绝，直到绑定完成。
- 自助绑定入口在「个人设置 → 安全」，本地密码账号与 LDAP 账号都可以自助绑定；OIDC 账号不适用（认证由 IdP 负责）。绑定前需要 5 分钟内的重新认证，LDAP 账号没有本地密码，直接用目录密码确认。
- 管理员在用户详情里可以「重置动态码」，用户下次登录会重新进入绑定流程。
- 查看 kubeconfig 也会要求动态码二次校验。
- 「系统设置 → 通用」里的动态码总开关若是关闭状态，则无法绑定——排障时先确认这里没被关掉。

### 敏感操作二次校验

开启后，删除类操作与打开交互式终端（Web 终端、Pod 终端、kubectl 终端）前会要求再输入一次动态码，通过后在「动态码校验有效期」内不再重复要求。

## 登录限制

### 失败锁定

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 用户连续失败次数 | 7 | 达到后锁定该账号 |
| 用户锁定时长 | 30 分钟 | 到期自动解锁 |
| IP 连续失败次数 | 5 | 达到后锁定来源 IP |
| IP 锁定时长 | 30 分钟 | 到期自动解锁 |

锁定期内即使密码正确也登录不了，登录日志里记的结果码是 `too_many_attempts`。页面上有「已锁定 IP」「已锁定用户」两张卡片，可以查看当前锁定项、立即解除，或手动拉黑某个 IP——手动拉黑会写进数据库，重启后依然有效，直到到期或被解除。

### IP 白名单与黑名单

- **白名单**：名单内的来源 IP **不参与失败锁定**（后端按白名单跳过计数）；默认已经放了两个内网地址（`10.100.117.5`、`10.100.240.93`），部署时要改成自己的运维网段。
- **黑名单**：直接拒绝，登录结果码是 `ip_denied`。
- 两种名单都支持单个 IP、CIDR 与地址区间，IPv6 同样适用。

### 登录来源与账号匹配

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 仅允许已存在的用户登录 | 关闭 | 第三方认证（OIDC）返回的用户名匹配不到本地账号时直接拒绝，不再自动开通（结果码 `not_provisioned`） |
| 仅允许从指定来源登录 | 关闭 | 开启后要求填写允许列表，**列表为空不允许保存**；不在列表内的来源被拒（结果码 `source_denied`；反代场景下判断依据是 `TRUSTED_PROXIES` 解析出的真实客户端 IP） |
| 仅一处设备登录 | 关闭 | 同一账号在新设备登录时，已登录的其它设备会被退出 |

多副本部署要注意：「仅一处设备登录」依赖副本之间共享会话状态，跨副本时判定可能滞后。

## 密码安全

### 密码规则

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 密码最小长度 | 8 | 普通用户改密、管理员重置时生效 |
| 管理员密码最小长度 | 8 | 管理员账号的独立下限 |
| 至少包含的字符类别数 | 3 | 可选 0～4；设置为 0 时按下面四个开关「全部要求」处理 |
| 大写字母 / 小写字母 / 数字 / 特殊字符 | 全部开启 | 与上一项配合 |

密码长度上限固定 **30**，不受设置影响。页面上可以额外写入「常见弱口令」字典（去重后按字典序保存），命中的密码直接拒绝。

### 过期与历史

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 密码过期天数 | 900 | 到期前每天提醒，到期后必须改密才能继续使用 |
| 禁止重复使用的历史密码数 | 5 | 改密时不能与最近若干个旧密码相同 |

改密成功后该账号已签发的令牌**立即失效**，需要重新登录。管理员重置密码后，会通知本人（必收事件），见[通知与公告](../features/notification-and-announcements.md)。

「改密日志」记录每次密码修改，见[审计与合规](../features/audit-and-compliance.md)。

## 会话安全

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 关闭浏览器时失效 | 开启 | 会话 cookie 不持久化，关掉浏览器即登出 |
| 最大空闲时长 | 600 分钟 | 超过该时长无操作自动登出 |
| 会话最大时长 | 24 小时 | 无论是否活跃，到点必须重新登录 |

配套行为：

- 访问令牌有效期固定 24 小时，与「会话最大时长」对齐；会话 cookie 的有效期是令牌的 2 倍，用于令牌轮换。
- 被顶下线时会有站内信提醒，页面也会提示已被其它设备登录。
- 24 小时内被顶替 3 次及以上，会给本人发一封邮件提醒（疑似密码泄露），通过「仅一处设备登录」之外的多点登录也能触发。

## 认证配置

「认证配置」页签管理认证源：

- **本地账号**：用户名 + 密码，是默认方式。
- **LDAP**：连接参数、同步方式（立即同步与周期同步，周期默认 10 分钟）、用户导入；目录用户第一次登录时会按配置自动开通或按「仅允许已存在的用户登录」拒绝。
- **OAuth / OIDC**：可以新增、编辑、启用、删除多个提供方（每个客户端独立配置）。绑定口径：优先按提供方的 `sub` 命中已有账号；`sub` 首次出现但用户名已存在时，首次登录即完成绑定；不同提供方之间的绑定冲突会被拒绝，需管理员处理。

OAuth 接入的完整步骤见 [OAuth 设置指南](./oauth-setup.md)；托管集群的认证委托见[托管 K8s 认证](./managed-k8s-auth.md)。

## 三权分立与权限

内置角色按职责划分，可以理解为四个岗位：

| 角色 | 职责 |
| --- | --- |
| 系统管理员 | 集群与资源管理、日常运维 |
| 安全管理员 | 用户、角色、安全策略与认证源 |
| 审计管理员 | 只读审计日志与访问日志，不改配置 |
| 只读管理员 | 全平台只读 |

约束与实现口径：

- **三权分立互斥**：系统管理员 / 安全管理员 / 审计管理员这三个角色不能由同一个账号兼任。一旦冲突，该账号访问管理面时会被**整体拒绝**（不只是拒绝个别接口），需要管理员先解掉冲突。
- 新增账号或调整角色时会做预检，冲突的角色组合直接拒绝；页面提供「角色冲突」列表用于排查存量冲突。
- **系统设置按章节授权**：`settings.*` 权限按设置章节逐一授权，`settings.*` 全通配**不覆盖**设置族，必须显式勾选；没有授权的章节在界面上不可见，接口也会拒绝。
- **权限绑定组**：把「集群 + 命名空间」范围的权限打包给一组用户，适合多集群下的分权运维。

完整配置步骤（角色、权限绑定组、章节授权）见 [RBAC 配置指南](./rbac-config.md)。

## 请求体凭据加密

登录口令、动态码、改密/重置口令、kubeconfig 与 Secret 内容都在浏览器侧加密后上行，服务端解包，
因此明文凭据不会留在访问日志、抓包和代理日志里。默认明文、密文都接受；设
`AEROLINK_REQUIRE_ENCRYPTED_CREDENTIALS=true` 后只收密文，明文凭据直接 `400`（`code` 为
`encrypted_credential_required`），适合在确认所有客户端都是当前版本之后收口。

三点取舍：它**不替代 HTTPS**（中间人仍可重放合法密文、篡改响应，TLS 仍是部署侧必做项）；私钥丢失
或副本之间不一致会让写操作随机失败，多副本必须共享同一份私钥；开启后自建脚本要改用密文。变量与
运维口径见[环境变量](./env.md)的「凭据传输加密」。

## API 密钥

API 密钥用于自动化调用平台 API（如 CI 里下发部署）。口径：

- 在个人设置里创建与撤销，创建时只在创建的那一刻显示一次完整密钥，之后不再回显。
- 密钥**继承创建者账号的角色与权限**，没有独立的 scope 字段——要收窄权限，就给专用账号分配最小角色，再用该账号创建密钥。
- 密钥属于敏感值，与其它敏感配置一样由 `AEROLINK_ENCRYPT_KEY` 加密存储，见[环境变量](./env.md)。
- 用密钥调用 API 会记进登录日志（登录方式为 API Key）。

## 相关环境变量与配置

| 项 | 说明 |
| --- | --- |
| `AEROLINK_ENCRYPT_KEY` | **必填**。加密存储敏感值（API 密钥、SMTP 口令、OAuth/LDAP 凭据等）。更换或丢失会导致已有敏感值无法解密 |
| `JWT_SECRET` | 签发访问令牌的密钥，必须固定；多副本要一致 |
| `TRUSTED_PROXIES` | 反向代理的 IP / CIDR 列表，决定真实客户端 IP 的来源，直接影响 IP 黑名单、登录来源限制与审计记录里的 IP |
| `ANONYMOUS_USER_ENABLED` | 开启匿名访问，仅用于演示环境，生产不要打开 |
| `AEROLINK_TRANSPORT_KEY_PATH` | 请求体凭据加密用的私钥路径，不存在时自动生成。多副本必须共享同一份 |
| `AEROLINK_REQUIRE_ENCRYPTED_CREDENTIALS` | 设为 `true` 后只接受密文凭据，明文提交返回 `400 encrypted_credential_required` |

完整清单见[环境变量](./env.md)与 [Chart 配置](./chart-values.md)。出口 HTTPS、CSP 头等由部署侧控制，见[构建并推送镜像](../guide/build-and-push-image.md)。
