# 新增五套 kkRepo 皮肤配色主题（靛蓝 / 海洋 / 落日 / JFrog / 星云）

- 状态：**已完成**
- 触发：`emerald`（墨绿）已按 kkRepo 的 `default` 皮肤对齐（见
  `2026-09-20-墨绿主题与kkRepo对齐.md`），用户要求把 kkRepo 其余五套皮肤也做成同口径的
  配色主题。
- 结论：新增 `indigo` / `ocean` / `sunset` / `jfrog` / `nexus` 五套主题，结构与
  `emerald.css` 完全一致；浅色逐项取自对应 kkRepo 皮肤，暗色按 kkRepo 深色系派生
  （`nexus` 例外，见 §5）。全部通过 `theme-contrast.test.ts`。

## 1. 参考对象

与墨绿同源：`kkRepo/browse-ui/src/main/resources/META-INF/resources/browse/assets/themes/`
下的 `indigo.css` / `ocean.css` / `sunset.css` / `jfrog.css` / `nexus.css`（Apache-2.0）。
每套皮肤的 token 名一致，只是取值不同，因此五套的映射表与墨绿同构，只有 §5 的
`nexus` 有结构性差异。

## 3. 结构

与 `emerald.css` 一模一样，只是把类名换成 `.color-<name>` / `.dark.color-<name>`：

1. 浅色块 `.color-<name>`：`--background: --canvas`、`--card: --surface`、
   `--muted: --header(= --surface-sunken)`、`--primary: --brand`、
   `--accent: --brand-tint`、`--accent-foreground: --brand-strong`、
   `--border: --line`、`--input: --line-strong`、`--attention: --accent`、
   状态色与 `-foreground`、`--chart-1..5`、侧边栏、`--table-head-ink`、
   `--row-hover`、`--radius: --r-md`、`--shadow-*`。
2. 暗色块 `.dark.color-<name>`：见 §4。
3. 主题作用域规则（只带 `.color-<name>` 前缀，不动 `ui/src/components/ui` 原语）：
   - 深色侧边栏的选中态实底 + 深字（`indigo` / `ocean` / `sunset` / `jfrog`，见 §5.1）；
     选中项的 `svg` 一并压成前景色。
   - 表格 `[data-slot='table-head']` 文字色与
     `[data-slot='table-row']:has([data-slot='table-cell']):hover` 悬浮底色
     （口径与墨绿相同，`nexus` 因浅侧边栏不需要侧边栏那条）。

## 4. 暗色派生（kkRepo 无暗色 token）

`indigo` / `ocean` / `sunset` / `jfrog` 与墨绿同规则，按皮肤自己的深色系 token 派生，
不引入 kkRepo 之外的色值：

- `--background: --topbar`、`--foreground: --topbar-ink`、`--card`/`--popover: --topbar-line`
- `--primary`/`--ring`/`--sidebar-primary`/`--sidebar-ring`: `--brand-bright`
- `--secondary: --ink-2`、`--muted: --ink-1`、`--muted-foreground: --topbar-muted`
- `--accent: --topbar-line`、`--accent-foreground: --brand-bright`
- `--destructive: --danger-line`、`--destructive-foreground: --ink-1`
- 侧边栏：`--sidebar: --ink-1`、`--sidebar-foreground: --topbar-ink`、
  `--sidebar-accent: --topbar-line`、`--sidebar-border: --topbar-line`
- `--chart-2/3/4: --info-line / --success-line / --warning-line`、`--chart-1: --brand-bright`、
  `--chart-5: --accent`
- `--table-head-ink: --topbar-muted`、`--row-hover: --topbar-hover`

暗色状态色（`success` / `info` / `warning` / `attention`）由浅色状态色向白提亮到
「在暗底/卡片/沉底/自身软底上都 ≥4.5、深色字压在上面也 ≥4.5」的最暗一档，取值为：

| | success | info | warning | attention | 深字（* -foreground） |
| --- | --- | --- | --- | --- | --- |
| indigo | `#7cb9a8` | `#95aced` | `#c9a672` | `#df9c81` | `#111827` |
| ocean | `#afd4c9` | `#b1d1e2` | `#dec8a8` | `#b2d3d1` | `#082f49` |
| sunset | `#76b49a` | `#84a9e8` | `#c9a272` | `#e29985` | `#2a151b` |
| jfrog | `#56a166` | `#7293c5` | `#ad8c59` | `#7293c5` | `#061121` |

（`jfrog` 的 `attention` 与 `info` 同值，源皮肤同色。）`ocean` 的 `--muted == --background`
（`--ink-1 == --topbar`，源皮肤如此），侧边栏也同色，靠 `--sidebar-border` 分隔。

## 5. `nexus` 的两处结构性差异

### 5.1 浅色侧边栏

kkRepo 其余皮肤的 `--topbar` 是深色，映射到侧边栏就是深色侧边栏；`nexus` 的
`--topbar` 是**白底**（`#ffffff`），映射后得到一支浅色侧边栏（前景 `--topbar-ink`
`#1f2226`、选中 `--brand` `#2f7650`）。这与本仓浅色默认主题的浅侧边栏一致，因此
**不需要**墨绿那套「亮色实底 + 深字」的选中态规则——默认的 `bg-primary/10` 铺底 +
`text-primary` 上色在浅底上就看得清楚。

### 5.2 暗色用自建中性阶翻面

`nexus` 的 `--topbar` 是白底，它没有可用的深色系 token（`--ink-1 #1f2226` 已经是
整套里最深的）。套用 §4 的派生式会得到「背景是白色」的假暗色主题。因此 `nexus` 的
暗色用自身的中性阶翻面，并用主色的浅化值作暗底上的主色：

| | 值 | 来源 |
| --- | --- | --- |
| `--background` | `#1f2226` | `--ink-1` |
| `--card`/`--popover`/`--accent` | `#2b2f34` | `--ink-1`/`--ink-2` 之间的深中性 |
| `--muted` | `#17191c` | 比页面底更暗一档 |
| `--secondary` | `#34383d` | `--ink-2` |
| `--foreground` | `#eceeef` | `--surface-sunken`（作浅色文字）|
| `--muted-foreground` | `#a9b0b6` | 中性阶上的次要文字色 |
| `--primary`/`--ring` | `#5cb98a` | 主色浅化值（kkRepo 的 `--brand`/`--brand-bright` 都偏深，暗底上作按钮底不到 AA）|
| `--accent-foreground` | `#7ec9a3` | 主色浅化值再提亮 |
| `--destructive` | `#e8bab6` | `--danger-line` |

这是五套里唯一引入 kkRepo 之外色值的地方，方法是把中性阶按深浅翻面，非随手取色。
暗色状态色同 §4 的提亮法取得：`success #87b19a` / `info #84aacb` /
`warning #c4a078` / `attention #84aacb`，深字 `#1f2226`。

## 6. 深色侧边栏的选中态规则（indigo / ocean / sunset / jfrog）

侧边栏是深底，菜单选中项默认 `bg-primary/10` + `text-primary`，而浅色模式下
`--primary` 是各皮肤的深主色（如靛蓝 `#4f46e5`），压在深侧边栏上对比度只有 2 上下，
看不清。与墨绿一致，改用 `--sidebar-primary`（= `--brand-bright`）实底 +
`--sidebar-primary-foreground` 深字的选中样式，选中项图标一并压成前景色。规则只带
`.color-<name>` 前缀，两种模式都生效（暗色下 `--sidebar-primary` 即 `--brand-bright`）。

## 7. 按 AA 微调的 token

kkRepo 的浅色状态色是给自家白色表面调的，压到本仓的沉底填充（`--muted` =
`--surface-sunken`）或自身 10% 软底上时个别不足 AA。只动不达标的，取同色相略加深：

| 主题 | token | kkRepo | 调整后 | 触发断言 |
| --- | --- | --- | --- | --- |
| indigo | `--warning` | `#a16207` | `#9d5f07` | warning / 沉底 4.38、warning / 软底 |
| indigo | `--muted-foreground` / `--table-head-ink` | `#64748b` | `#606f85` | 说明 / 页面底 4.48、说明 / 沉底 4.23 |
| indigo | `--attention` | `#c2410c` | `#c1410c` | attention / 软底 4.48 |
| ocean | `--warning` | `#a16207` | `#9d5f07` | warning / 沉底 4.38 |
| sunset | `--warning` | `#a15c07` | `#a05b07` | warning / 沉底 4.49 |
| nexus | `--success` | `#347a53` | `#347953` | success / 沉底 4.45 |

`jfrog` 全部文字 token 沿用 kkRepo 原值。

## 8. 暗色描边：刻意不取自 kkRepo

与墨绿同一处例外：kkRepo 的暗色系里没有任何可作描边的 token，若拿 `--topbar-line`
同时当 `--card` / `--border` / `--input`，卡片描边与输入框边界都是 1.00:1（完全看不见）。
五套统一改用本仓其余暗色主题一致的半透明白描边（`--border: oklch(1 0 0 / 14%)`、
`--input: oklch(1 0 0 / 22%)`），只影响这两个 token。

## 9. 刻意不映射的 kkRepo token

与墨绿 §5 同一份清单（`--surface-muted`、`--brand-tint-strong`、`--accent-soft`、
`--ink-4`、状态的 `-bg`/`-line`、`--account-avatar-*`、`--focus`、`--topbar-selection`、
`--r-*`/`--s-*`/`--fs-*`/`--fw-*`/`--lh-*`），五套皮肤这些 token 在 AeroLink 里都没有
消费方，照抄就是死变量，不映射。
