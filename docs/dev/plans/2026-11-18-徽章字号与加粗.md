# 集群徽章说明与图标文本的排版设置

## 背景与目标

集群徽章的「自定义说明」与「图标文本」原来都是固定排版（说明 `text-xs` + `font-medium`，
图标文本按展示位置 8 / 9 / 11px）。多集群下管理员需要把「生产」这类标识做得更显眼、或
缩小以少占位，两者的诉求并不总是同步。目标：

1. 说明文本支持**自定义字号**（10~24px，预设档位 10 / 12 / 14 只是快捷值），默认 12px =
   原来的排版，升级后外观不变；另有**加粗**、**背景色**与**字色**，都默认沿用原样。
2. 图标文本有**自己的一套**：字号（自动 / 小 / 标准 / 大）、**加粗**、**字色**。
   默认「自动」= 沿用按位置自适应的 8 / 9 / 11px，「字色」留空 = 按徽章底色自动取黑/白字，
   升级后外观同样不变。
3. 两处互不联动：改说明的字号不会带动图标文本，反之亦然。
4. 展示端（顶栏、创建页「当前集群」、集群管理列表、切换器）与配置弹窗预览一致。

## 数据模型

`clusters` 表新增 7 列（`pkg/model/cluster.go`）：

| 列 | 类型 | 含义 |
| --- | --- | --- |
| `badge_text_size` | varchar(8)，空 = 默认档 | 说明字号：`sm` / `md` / `lg`（10 / 12 / 14px）或 10~24 的整数像素值 |
| `badge_bold` | boolean, default false | 说明是否加粗 |
| `badge_text_color` | varchar(16)，空 = 自动 | 说明字色 `#RRGGBB`（空值按 `badge_color` 自动取黑/白） |
| `badge_icon_text_size` | varchar(8)，空 = 自动 | 图标文本字号：`sm` / `md` / `lg` |
| `badge_icon_text_color` | varchar(16)，空 = 自动 | 图标文本字色 `#RRGGBB` |
| `badge_icon_text_background` | varchar(16)，空 = 用徽章背景色 | 图标文本底色 `#RRGGBB` |
| `badge_icon_bold` | boolean, default false | 图标文本是否加粗 |

所有「空值」都不设列默认：老行是空串，渲染时按各自默认档处理，升级不需要回填；
空串本身也是合法取值（「改回默认 / 自动」）。两个 boolean 的默认 false 与老行零值一致。

**这是库结构变更，升级前需要手工执行 SQL**（生产库的应用账号通常不是表 owner，
PostgreSQL 上 `AutoMigrate` 加列会被拒；见 `docs/dev/release-checklist.md` §1.1 与
`docs/guide/installation.md` 的「升级」一节，两处都要同步维护）：


## 校验（fail-closed）

`validateClusterBadge`（`pkg/cluster/cluster_handler.go`）在原有的文本长度、颜色格式
之外增加：

- `badgeTextSize` 接受 `""` / `sm` / `md` / `lg`，或 **10~24 的十进制整数**（自定义像素
  字号）。其余一律 400（含大小写不同的 `LG` 与 `12px` 这种带单位的写法：不做静默归一化，
  否则用户以为写进去的是别的档位）。
- `badgeIconTextSize` 仍只有 `""` / `sm` / `md` / `lg` 四档，不开放自定义像素。
- `badgeTextColor` / `badgeIconTextColor` / `badgeIconTextBackground` 非空时必须匹配 `^#[0-9a-fA-F]{6}$`：
  它们会进前端内联样式，与 `badgeColor` 同一条口径。
- 两个 `Bold` 字段是布尔值，无需额外校验。

前端渲染时再兜一层：字号未知值回落各自默认档，字色非法值回落「按底色自动」。

## 说明与图标文本各自独立

两处是独立的配置：说明读 `badgeTextSize` / `badgeBold` / `badgeTextColor`，图标文本读
`badgeIconTextSize` / `badgeIconBold` / `badgeIconTextColor` / `badgeIconTextBackground`，
互不取值。

`badgeIconTextSize` 为空时，图标文本仍按 `ClusterBadgeIcon` 的 `size`（下拉项 / 默认 /
弹窗预览 → 8 / 9 / 11px）自适应；显式选档后固定为 10 / 12 / 14px。

## 取舍

- **用固定档位而不是自由字号**。自由数值必须进内联样式，等于把样式注入面交出去；
  三档覆盖实际需求，也便于保证行高与内边距一起调整（只放大字号会让文字顶出圆角）。
- **图标文本的「自动」保留位置自适应**，不改成固定值：老集群不设置时外观不变，
  而下拉项 / 弹窗预览本来就需要不同尺寸。
- **说明与图标文本都开放「字色 + 底色」**：只给字色的话，红底红字直接看不见。说明的底色
  沿用原有的「徽章背景色」（`badge_color`，同时是图标文本的默认底色），说明自己的字色是新增的
  `badge_text_color`；图标文本则另有一套底色，避免改说明底色连带改掉图标。留空分别回落
  「按背景自动黑白」与「徽章底色」，默认配置始终可读。
- **自动黑白按实际底色计算**：图标底色换了之后，字色仍按最终渲染出来的底色算对比度。
- **空值即默认**，不写成 `default 'md'`：老数据升级不做回填，语义也更明确
  （「没设置过」与「显式选了标准」在渲染上等价）。
