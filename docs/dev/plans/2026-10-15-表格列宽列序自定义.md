# 表格列宽拖拽全量推广 + 列顺序拖拽

日期：2026-10-15

## 背景与目标

列宽拖拽（TanStack `enableColumnResizing` + localStorage 持久化）目前只在
`ResourceTable`（资源列表页）里落地。需求：

1. 把列宽拖拽推广到其余表格：设置页各 TanStack 表格、`ActionTable`、
   `SimpleTable` 系列自定义表。
2. 新增「列顺序拖拽」：表头拖动换位，TanStack `columnOrder` + 持久化。
3. 修复列宽调整线在部分主题下看不清的问题（对比度走语义 token）。

## 现状盘点

| 表格族 | 文件 | 现状 |
| --- | --- | --- |
| 资源列表页（约 30 个页面） | `ResourceTable` → `ResourceTableView` | 已有列宽拖拽 + 持久化 |
| 设置页表格 | `settings/audit-log`、`login-log`、`password-change-log`、`archive-query`、`user-management`、`user-groups-tab`、`rbac-management`、`rbac-permission-catalog` | `useReactTable` + `ResourceTableView`，只有列显示偏好（`useTableColumnVisibility`），无列宽/列序 |
| 操作表格 | `action-table.tsx` | 已开 resizing，但手柄是第二份拷贝实现 |
| 简单表格 | `simple-table.tsx`（event/service/volume/related-resource/resource-history/workload-revisions 等使用） | 原生 table，无 TanStack，无任何自定义 |

拖拽手柄视觉：`ResourceTableView` 用 `bg-transparent hover:bg-primary/40`，
拖动中 `bg-primary`——`primary` 落在 `bg-muted` 表头上时，部分主题（深色、
低饱和 primary）对比不足。

## 方案

### 1. 共享拖拽手柄 `ui/src/components/column-resize-handle.tsx

把手柄抽成一个纯展示组件（输入：是否拖动中 / 事件回调），三处共用：

```tsx
<span
  role="separator"
  draggable={false}                       // 防止拖手柄时触发列顺序拖拽
  className="... after: 竖线 ..."
/>
```

对比度修复（全部走语义 token，不新增 Tailwind 色阶）：

- 命中区 `w-2` 贴表头右缘，靠 `group-hover/th` 在悬停**整个表头**时显形；
- 静态/hover：`after:bg-transparent` → `after:bg-primary/40`（2px 圆角竖线）；
- 拖动中：`after:bg-primary` 外加 `after:shadow-[0_0_0_1px_var(--background)]`
  ——一圈 `--background` 描边保证任何主题下都与表头底色拉开对比；
- 加 `title` 提示「拖动调整列宽，双击恢复默认」。

`ResourceTableView` 的表头加 `group/th`（原来只有手柄自身 hover 才显形，
命中区太窄）；`ActionTable` 改用共享组件删掉本地实现。

### 2. 列顺序拖拽（TanStack 表格族）

- 无新依赖：HTML5 DnD 拖动 `<th>`（触屏不支持，内网桌面场景可接受）。
- `useReactTable` 接 `state.columnOrder` / `onColumnOrderChange`；
  `ResourceTableView` 新增 `enableReorder` prop，命中即启用。
- 规则：`select`（勾选列）与 `actions`（操作列）不可拖、不可作落点，
  重排后强制保持「勾选列最左、操作列最右」；其余列自由换位。
- 落点指示：目标列左/右缘 `shadow-[inset_2px_0_0_0_var(--primary)]`。
- 持久化：资源列表页存 `aerolink-<resource>-columnOrder`（沿用
  `getClusterScopedStorageKey`），设置页存 `aerolink-<页面>-columnOrder`。
  存储里多出来的陈旧列 id 会被 TanStack 忽略、缺失的列按默认顺序追加，
  无需清理逻辑。
- 重置：`TableColumnToggle`（齿轮菜单）底部加「恢复默认列布局」，清空
  columnOrder + columnSizing。

### 3. 设置页表格接入（8 个文件）

新增 `ui/src/hooks/use-table-column-preferences.ts`：
`useTableColumnSizing(storageKey)`、`useTableColumnOrder(storageKey)`
（与 `use-table-column-visibility` 同一套 localStorage 模式）。
各设置页表格：接两个 hook + `enableColumnResizing/columnResizeMode/
defaultColumn{size:160,min:80,max:600}` + `enableReorder`。

### 4. SimpleTable（非 TanStack）

- 新增 `storageKey?: string` prop：传入即启用列宽拖拽 + localStorage 持久化
  （按列下标存宽度）；不传则行为完全不变。
- 自实现 pointer 拖拽（ TanStack 的 header API 在这里拿不到）：
  `pointerdown` 记录起点与当前列宽，`pointermove` 实时更新（下限 80px），
  `pointerup` 结束并落盘。
- 布局保持 `table-auto`，被拖过的列写 `width + minWidth` 像素（与资源列表
  自动布局模式同一模型），未拖过的列继续按内容自适应。
- 不做列顺序拖拽（列没有稳定 id，收益也小）。
- 使用方传 key：`event-table`、`service-table`、`volume-table`、
  `related-resource-table`、`resource-history-table`、`workload-revisions-table`
  及 4 个直接使用的详情页。

### 5. i18n

`zh.json`（事实来源）+ `en.json` 新增：
`resourceTable.resetColumnLayout`、`resourceTable.columnResizeHint`。

## 不做的事

- 不动 `ui/src/components/ui/table.tsx` 原语。
- 不给分组表（grouping）、行详情行做列序支持（组标题行是 colSpan 全宽）。
- 不引入 dnd-kit。
