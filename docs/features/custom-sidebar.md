# 自定义侧边栏

左侧栏的分组和菜单项可以按自己的习惯排序、隐藏。布局默认只影响自己；管理员可以把一套布局设为全局默认。

## 打开

头像菜单 →「自定义侧边栏」。

![自定义侧边栏：① 分组与计数 ② 显示 / 隐藏与排序 ③ 全局操作 ④ 恢复默认](/images/usage/custom-sidebar-demo-guided.png)

| 编号 | 位置 | 能做什么 |
| --- | --- | --- |
| ① | 分组标题 | 显示当前分组可见项 / 总项数（如 `6/6`），右侧可整组收起、置顶、上移下移 |
| ② | 每个菜单项 | 拖动手柄排序；眼睛图标显示 / 隐藏；置顶 / 收起 |
| ③ | 底部右侧 | 「设为全局侧边栏」把当前布局发布给所有没自定义过的账号；「取消全局侧边栏」撤销全局布局 |
| ④ | 底部左侧 | 「恢复默认」清掉自己的自定义，回到默认顺序 |

## 生效规则

- 改完点「完成」保存，左侧栏立即按新布局显示。
- **个人布局优先**：自己配过就用自己的；没配过才跟随管理员的全局布局。
- 隐藏的菜单只是不显示入口，权限与资源不受影响；要找回被隐藏的项，重新打开这个弹窗打开眼睛开关即可。
- 「设为全局侧边栏」需要管理员权限，普通账号看不到这两个按钮。

::: tip 找不到某个资源类型
先看「其他」分组（默认折叠、部分类型默认隐藏），或直接在自定义侧边栏里搜索/展开对应分组打开开关。
:::
