# 全局搜索

鸢联 AeroLink 提供强大的全局搜索功能，让您可以快速查找集群中的任何资源。您可以通过资源名称、标签或注解进行搜索。

你可以通过顶部的搜索栏或者在任意界面使用快捷键 `Ctrl + K` (Windows/Linux) 或 `Cmd + K` (macOS) 来激活全局搜索。

![全局搜索：① 搜索输入 ② 导航结果 ③ 资源结果 ④ 收藏星标](/images/usage/global-search-demo-guided.png)

结果分两组：

- **导航**：直接跳页面（资源类型、设置页等）；
- **资源**：当前集群里匹配名称的资源，显示类型与命名空间，右侧星标可收藏。

| 编号 | 位置 | 说明 |
| --- | --- | --- |
| ① | 输入框 | 输 3 个字符以上才触发搜索 |
| ② | 导航分组 | 按名称匹配页面 / 资源类型 |
| ③ | 资源分组 | 匹配到的具体资源，点击直达详情 |
| ④ | 星标 | 收藏常用资源，下次打开搜索时置顶 |

## 支持功能

### 收藏

点击资源右边的小星星之后，即可以收藏这个资源，下次激活全局搜索时，可以在列表中快速找到。

### 搜索指定资源

您可输入资源名称的前缀加上空格和你想输入的搜索词，例如：

```
pod nginx
```

这样讲只搜索名称以 `nginx` 开头的 `Pod`。

`pod` 也可以缩写成 `po`

更多支持的资源类型和缩写，见仓库源码 `pkg/utils/search.go` 与 `pkg/common` 中的别名表。

## 限制

- 为了性能考虑，当输入的字符长度小于 3 时，搜索将不会被触发
- 不支持模糊搜索
- 不支持跨集群搜索
- 搜索会对集群发起 listAll 请求，因此如果集群中资源数量过多，可能会导致搜索变慢。（鸢联 AeroLink 会对搜索结果缓存 10 分钟）

## 已知问题

当 RBAC 规则限制用户无法访问某些资源时，这些资源仍然会出现在搜索结果中。

但是如果您尝试访问这些资源，将会收到权限错误。

这是一个已知问题。暂时将不会修复。

搜索接口仅返回资源名字和类型，不会返回具体内容。
